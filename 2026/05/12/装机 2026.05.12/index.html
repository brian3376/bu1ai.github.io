2.散热器

利民 pa120se

双塔式的风扇，反正记得不能装反，不然温度会很高

（！！！注意AMD和inter是反过来的，如果装反显卡放不进去[别问为什么我会知道]！！！）

利民 PA120 SE 自带的是**正转风扇**，风扇有 logo 的一面是进风面，骨架那面是出风面，所以安装时：

  1. 风扇骨架（出风面）贴着散热鳍片，logo 面朝外。
  2. 两个小正方形的 logo 侧对着内存条，长方形侧对着机箱尾部，这样风向才是正确的。
  3. 螺丝也不要拧太紧，一边转2圈，直到到弹簧螺丝感觉到压力较大，散热器牢固即可（太紧会压到cpu和主板）

day5

重新制作了启动u盘

1.使用微PE工具箱制作u盘启动

发现联想电脑可以进入 ，但是华硕进不去

2.搜索，尝试建立纯净UEFI

，微PE工具箱的默认三分区，华硕是进不去的，只能使用单分区

这个是因为

华硕（尤其 2020 年后新主板）：UEFI 校验严格，不认三分区 / 多分区 U 盘，只认：

  • GPT 单分区 + FAT32 + 纯 UEFI
  • 或 MBR 单分区 + NTFS + Legacy

白天上班直接准备好UEFI单分区启动u盘和驱动 ，

晚上回来直接重装win11 打上驱动 直接ok

Ⅲ 测试

打算用下面三个工具来测一遍

MemTest64 AIDA64 FurMark

第一步：先测内存（MemTest64）

  • 原因：内存不稳会导致其他测试结果失真，先把它搞定。
  • 操作：
    1. 打开 MemTest64，勾选 “使用所有可用内存”（注意别把系统盘吃满，留个 2-4G 余量）
    2. 跑完整测试，至少跑 2-3 轮，0 报错才算合格。
  • 重点：只要出现 1 个错误，就说明内存有问题，检查一下双通道有没有插对、主板内存插槽有没有选对、BIOS 里 EXPO 有没有开。

第二步：测 CPU / 主板稳定性（AIDA64 单烤 FPU）

  • 操作：
    1. 打开 AIDA64 → 工具 → 系统稳定性测试
    2. 只勾选 <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">FPU</font>（别勾其他的，避免负载太高），跑 15-30 分钟
  • 重点：
    • <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">7800X3D</font> 满载温度：不超过 90℃算正常，PA120 SE 压得住的话，一般在 80℃上下。
    • 频率：看有没有一直降频、撞温度墙的情况。
    • 主板 VRM 温度：不超过 90℃，说明供电没问题。

第三步：测显卡稳定性（FurMark）

  • 操作：
    1. 打开 FurMark，设置分辨率和你显示器一致，勾选 “极端折磨模式”
    2. 跑 15-30 分钟
  • 重点：
    • <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">RTX 5060 Ti</font> 满载温度：不超过 85℃算正常，超级冰龙的散热表现一般都不错。
    • 功耗：稳定在 160-200W 左右，频率稳定不降，不出现驱动重置、花屏、黑屏。
